# Add Native Mobile Shells

## Why

PWA support (added by `2026-08-14-pwa`) gets the app
installable, but native shells deliver better UX: home-screen
icons, real back-button, native push notifications, camera
integration for receipt scanning. Crater ships native iOS +
Android via React Native; Akaunting has Capacitor wrappers.

The PWA change already lays the groundwork (offline cache,
manifest). This change packages the existing web UI into
installable iOS and Android apps using **Capacitor**, the
same web-to-native bridge that Akaunting uses. No new
functionality in v1 — just the native shell + push hooks.

## What Changes

- New directory `mobile/` at the repo root with:
  - `mobile/capacitor.config.ts`
  - `mobile/package.json`
  - `mobile/src/` — minimal Capacitor app that wraps the
    server-rendered web app at `https://<host>` (configurable
    per build).
  - `mobile/ios/` — Xcode project (generated by
    `npx cap add ios`).
  - `mobile/android/` — Gradle project.
- New CI workflow `.github/workflows/mobile-build.yml` that
  builds both shells on tag.
- New push-notification integration:
  - Server side: new `notifications` module
    (`src/handlers/notifications.rs`) with a `POST
    /devices/register` endpoint that stores an APNs/FCM token
    per user.
  - Client side: Capacitor `PushNotifications` plugin reads the
    token and posts it on login.
- Triggers that fire notifications:
  - Reimbursement claim awaiting your approval
    (`approval_policies` change).
  - Bank-feed sync completed with N new transactions.
  - Document OCR finished.

## Capabilities

### New Capabilities

- `mobile` — installable iOS and Android shells via
  Capacitor.
- `notifications` — device token registration and push
  dispatch.

## Impact

- **New files:**
  - `mobile/` (entire Capacitor app, ~30 files)
  - `.github/workflows/mobile-build.yml`
  - `migrations/0025_add_device_tokens.sql`
  - `src/handlers/notifications.rs`
  - `src/notifications/{apns,fcm}.rs`
  - `tests/integration/notifications.rs`
- **Modified files:**
  - `Cargo.toml` — `apns-rust = "0.2"`, `fcm = "0.10"` behind
    feature flags.
  - `src/config.rs` — `apns_key_path`, `fcm_service_account_path`.
  - `src/main.rs` — register notification routes.

## Non-Goals

- Mobile-only features (different UX from web). v1 is the
  same web app in a native shell.
- App Store / Play Store submission automation. The CI
  produces signed builds; humans publish.
- Offline writes (separate change).
- Biometric authentication (separate change).
